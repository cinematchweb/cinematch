# Decisiones técnicas de CineMatch

## Estructura
- HTML, CSS y JavaScript.
- Arquitectura modular.
- Separación de estilos, páginas, componentes y servicios.
- Desarrollo realizable desde Android.

## Backend
- Supabase como plataforma de backend.
- PostgreSQL para la base de datos.
- Supabase Auth para autenticación.
- RLS para proteger los datos.

## Autenticación
- Prioridad inicial: correo electrónico.
- Google OAuth se implementará posteriormente.

## Desarrollo
- Termux como entorno de trabajo móvil.
- GitHub como repositorio y respaldo.
- Priorizar herramientas gratuitas.
- Mantener intacto el ZIP original.

## Producto
- Primero conseguir una versión funcional.
- Después añadir funciones sociales avanzadas.
- No implementar chats antes de completar las funciones principales.

## Contenido
- API cinematográfica prevista: TMDB.
- Noticias reales pendientes de integración.

## Seguridad
- Nunca subir contraseñas, tokens privados ni secretos.
- No incluir archivos .env reales en GitHub.
